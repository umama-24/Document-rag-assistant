# Local RAG Document Assistant 🚀

A private, secure, and local Retrieval-Augmented Generation (RAG) assistant built for document Q&A. Powered by open-source models with zero API costs.

## 🛠️ Tech Stack
- **UI:** Streamlit
- **LLM:** Ollama (Mistral)
- **Embeddings:** SentenceTransformers (`all-MiniLM-L6-v2`)
- **Vector Search:** FAISS
- **PDF Parsing:** pdfplumber

## ✨ Features
- 100% Local & Private (Runs completely offline via Ollama)
- Dynamic Reference Tracing (Displays exact page numbers and text excerpts)
- Zero Dependency Crashes (Optimized native Streamlit UI components)
